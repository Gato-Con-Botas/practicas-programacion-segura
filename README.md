# Prácticas de Programación Segura

Repositorio dedicado a recopilar las prácticas de laboratorio, ejercicios y proyectos desarrollados en la materia de Programación Segura.

## 🎯 Objetivos de la materia
- Diseñar e implementar software con principios de defensa en profundidad.
- Mitigar vulnerabilidades comunes (inyecciones, desbordamientos, exposición de datos).
- Ejecutar análisis estático y dinámico de código fuente.
- Aplicar estándares de la industria (OWASP Top 10, CWE).

## 📂 Contenido del repositorio
- `practica-01/`: Nombre del tema / breve descripción.
- `practica-02/`: Nombre del tema / breve descripción.

## ⚠️ Nota académica
El código y las pruebas de concepto contenidas en este repositorio tienen fines estrictamente pedagógicos y de laboratorio controlado.
